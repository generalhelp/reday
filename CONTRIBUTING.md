# Contributing

RE:DAY is currently an early hackathon project.

## Suggested workflow

1. Create a feature branch.
2. Keep commits small and descriptive.
3. Do not commit secrets or API keys.
4. Keep story content separate from UI logic where possible.
5. Open a pull request with a short description of the change.

## Example commit messages

```text
feat: add story engine
feat: add loop reset logic
feat: add memory system
feat: add dialogue screen
fix: preserve discovered memories after reset
```
